2. Docker Image / Docker Compose 启动命令
------------------------------------------------------------
环境要求：X64 架构的 Linux 主机（或装有 Docker Desktop 的 Windows/Mac），已安装 Docker 与 Docker Compose。

方式一（推荐，一条命令启动完整平台）：
进入项目根目录（含 docker-compose.yml），执行：

    docker compose up -d --build

等待镜像构建与数据库初始化完成后，访问：

    前端页面：http://localhost        （或服务器公网 IP）
    后端 API ：http://localhost:3000

方式二（直接使用交付的镜像产物包，无需构建）：
将随作业提交的镜像包导入：

    docker load -i football-backend-image.tar.gz
    docker load -i football-frontend-image.tar.gz

导入后用容器运行即可（数据库需按下方第 3 节配置连接，或直接使用方式一）。

其他常用命令：

    docker compose ps                    查看运行状态
    docker compose down                  停止服务
    docker compose down -v && docker compose up -d --build   重置演示数据

3. 数据库与资源文件挂载说明及配置方法
------------------------------------------------------------
(1) 数据库初始化
    容器 mysql 首次启动时，自动执行挂载的初始化脚本：
        ./db/init.sql → /docker-entrypoint-initdb.d/init.sql
    脚本会创建数据库 football_db、6 张业务表并导入全部种子数据
    （30 场比赛、14 个账号、讨论帖与预测记录）。

(2) 数据持久化
    使用命名卷 mysql_data 挂载到 /var/lib/mysql，容器删除后数据仍保留；
    如需全新初始化演示数据，执行 docker compose down -v 后重启。

(3) 数据库配置
    连接配置在 docker-compose.yml 的 mysql 服务环境变量中：
        MYSQL_ROOT_PASSWORD / MYSQL_DATABASE / MYSQL_USER / MYSQL_PASSWORD
    后端通过环境变量连接数据库（backend 服务）：
        DB_HOST=mysql  DB_PORT=3306  DB_USER=football  DB_PASSWORD=football123  DB_NAME=football_db
    如需修改，改 docker-compose.yml 后 docker compose up -d 重启即可。

(4) 资源文件
    前端为构建产物（nginx 静态托管），无需额外挂载；若需持久化上传类资源，
    可在 frontend 服务中自行挂载卷（本项目未使用文件上传）。

5. 演示流程（核心演示点：虚拟时间）
------------------------------------------------------------
本项目所有比赛时间均为"虚拟时间"，演示者可通过管理员时间控制台手动推进
时间，完整演示"未开赛 → 进行中 → 已完赛"的比赛生命周期：
预测 → 比分刷新 → 积分结算 → 讨论区开放。

演示步骤：
  (1) 打开首页，可看到按"未开赛 / 进行中 / 已完赛"三组展示的 30 场比赛，
      右上角显示当前虚拟时间：2026-07-10 12:00:00；
  (2) 注册新用户（或用演示账号登录，演示账号密码均为 123456，用户名以"小"字开头，
      如：小射手），对一场"未开赛"的比赛提交比分预测；
  (3) 退出登录，用 admin / admin123 登录，点击右上角"时间控制台"，
      按 +15 分钟 / +1 小时推进虚拟时间（或直接设定时间）；
  (4) 回到首页：进行中的比赛显示实时比分（LIVE），随时间推进变为"已完赛"，
      比分刷新展示；积分自动结算（猜中比分 +3 分、猜中胜负平 +1 分），
      讨论区自动生成球迷帖子与评论；
  (5) 登录普通用户，进入比赛详情页查看预测结算得分，参与讨论区发帖与评论；
  (6) 个人中心查看预测记录（含每场 +0/+1/+3 得分）与累计积分。
