- **进行中 2 场**（id 6、22）：7 条预测，完赛后自动结算

- **全部 30 场比赛均有预置帖子**（每场 1~2 条），**每条帖子均有评论**
- 已完赛 8 场的帖子（id 1~11）：赛后感言风格
- 进行中/未开赛 22 场的帖子（id 12~35）：赛前预测/展望风格，比赛完赛后即出现在讨论区
- 作者均为可登录的演示账号；另有 4 个球迷账号作为运行时兜底（仅当某场比赛意外缺失内容时自动补发）

## 六、重置方式

- Docker：`docker compose down -v && docker compose up -d --build`
- 本地：重新执行 `db/init.sql`（脚本含 DROP TABLE 重建逻辑，重复执行安全）
